## Functional Requirements

- The system shall provide a conversational interface that allows users to interact with the chatbot using natural language.

- The system shall record and store the history of conversations between the user's account and the chatbot.

- The system shall provide a dedicated chat window where users can enter messages and receive responses from the chatbot.

- The system shall allow users to switch between light mode and dark mode.

- The system shall provide a separate conversation history panel where users can view their previous conversations.

- The system shall provide an interface that allows users to start a new conversation.

- The system shall allow users to continue previous conversations from the conversation history.

- The system shall process the message entered into the chat input field when the user selects the Send button.

- The system shall allow users to select and delete one or more conversations from their conversation history.

- The system shall provide an elapsed time counter showing how long the chatbot has been generating a response.

- The system shall display an informative error message when an operation fails, explaining the nature of the error where possible.

- The system shall allow the user to login using their email address and password.

- The system shall allow the user to create a new profile using their email address and password.

- The system shall allow the user to reset their password through the log in interface.
