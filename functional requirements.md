## Functional Requirements

- The system shall provide a conversational interface that allows users to interact with the chatbot using natural language.

- The system shall provide functional user interface elements to support interaction with the chatbot.

- The system shall record and store the history of conversations between the user and the chatbot.

- The system shall provide a dedicated chat window where users can enter messages and receive responses from the chatbot.

- The system shall allow users to switch between light mode and dark mode.

- The system shall provide a separate conversation history window where users can view their previous conversations.

- The system shall provide an interface that allows users to start a new conversation.

- The system shall allow users to continue previous conversations from the conversation history.
